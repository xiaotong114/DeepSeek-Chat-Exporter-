# DeepSeek 对话全文抓取器

一个用于 DeepSeek 聊天页面的油猴脚本工具集，支持自动滚动加载并保存完整对话为 TXT 文件，并提供单对话抓取、批量抓取、关键词过滤、合并导出等进阶功能。

## ✨ 功能概览

- 自动识别滚动容器，模拟滑动触发懒加载
- 支持向上、向下、双向抓取
- 可调节滚动间隔和步长（毫秒/像素）
- 实时显示抓取进度、消息条数和字符数
- 停止后自动下载 TXT 文件（每条消息以 `---` 分隔）
- 可折叠面板，界面美观（美化版）
- 批量抓取多个对话、关键词筛选、合并导出（新版专属）

## 📦 版本说明

| 版本 | 文件名 | 主要特性 |
|:---|:---|:---|
| **基础版** | `deepseek对话完整复制.user.js` | 单对话滚动抓取，简洁稳定，无额外依赖 |
| **美化版** | `deepseek对话完整复制（ui更加美丽） .user.js` | 基础版功能 + 毛玻璃UI、可折叠面板，更美观 |
| **轻量导出版** | `ds对话导出（ui简化）.js` | 单对话 + 批量抓取、关键词过滤、合并导出，UI轻量化，适合性能不佳的设备 |
| **美化导出版** | `ds对话导出（美化版）.js` | 单对话 + 批量抓取、关键词过滤、合并导出，毛玻璃UI，功能最全 |

> 💡 推荐使用 **美化导出版**（`ds对话导出（美化版）.js`）以获得最完整的功能和最佳视觉体验。

## 🚀 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 选择对应版本的脚本文件，复制全部代码。
3. 打开 Tampermonkey 控制面板，点击“新建脚本”，粘贴并保存。
4. 访问 [DeepSeek 聊天页面](https://chat.deepseek.com/)，右侧会出现控制面板。

## 🎮 使用方法

### 单对话抓取（所有版本）

1. 进入任意对话页面，控制面板会自动出现。
2. 点击 **向上滚动抓取**、**向下滚动抓取** 或 **抓取全部**（先上后下）。
3. 可调整 **间隔(ms)** 和 **步长(px)** 以优化速度。
4. 抓取完成后自动下载 TXT 文件。

### 批量抓取（新版专属：ds对话导出 系列）

1. 切换到 **批量抓取** 模式。
2. （可选）输入关键词过滤对话标题（留空则抓取所有对话）。
3. 选择导出方式：**每个对话独立文件** 或 **合并为一个文件**。
4. 点击 **开始批量抓取**，脚本将自动依次访问每个对话并抓取。
5. 可随时 **暂停并保存** 已抓取内容，或 **停止（不保存）**。
6. 合并模式会在全部完成后自动下载合并文件。

## ⚙️ 参数建议

| 场景 | 间隔(ms) | 步长(px) |
|:---|:---|:---|
| 稳定抓取（基础版默认） | 1200 | 400 |
| 快速抓取（美化版/导出版） | 40 ~ 100 | 800 ~ 1000 |

> 💡 提示：使用桌面版网站（电脑 UA）效果更佳，批量抓取时建议保持页面在前台。
