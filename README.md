# DeepSeek 对话全文抓取器

一个用于 DeepSeek 聊天页面的油猴脚本工具集，支持自动滚动加载并保存完整对话为 TXT / MD / HTML 文件，并提供单对话抓取、批量抓取、关键词过滤、增量导出等进阶功能。

## ✨ 功能概览

- 自动识别滚动容器，模拟滑动触发懒加载
- 支持向上、向下、双向抓取
- 可调节滚动间隔和步长（毫秒/像素）
- 实时显示抓取进度、消息条数和字符数
- 停止后自动下载文件（支持 TXT / MD / HTML）
- 可折叠面板，亮暗主题切换（美化版）
- 批量抓取多个对话、标题关键词筛选
- 导出前可选轮次、开关思维链

## 🚀 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 选择对应版本的脚本文件（根据上方表格找到你需要的版本），复制全部代码。
3. 打开 Tampermonkey 控制面板，点击“新建脚本”，粘贴并保存。
4. 访问 [DeepSeek 聊天页面](https://chat.deepseek.com/)，右侧会出现控制面板。

## 🎮 使用方法

### 单对话抓取（所有版本）

1. 进入任意对话页面，控制面板会自动出现。
2. 点击 **向上滚动抓取**、**向下滚动抓取** 或 **抓取全部**（先上后下）。
3. 可调整 **间隔(ms)** 和 **步长(px)** 以优化速度。
4. 抓取完成后自动下载文件（格式取决于版本）。

### 批量抓取（`2.0/` 及新版）

1. 切换到 **批量抓取** 模式。
2. （可选）输入关键词过滤对话标题（留空则抓取所有对话）。
3. 点击 **开始批量抓取**，脚本将自动依次访问每个对话并抓取。
4. 可随时 **暂停/继续** 或 **停止**。
5. 新版还支持：
   - **选轮次导出**：自由选择导出哪些轮次
   - **多格式导出**：TXT / MD / HTML


## ⚙️ 参数建议

| 场景 | 间隔(ms) | 步长(px) |
|:---|:---|:---|
| 稳定抓取（基础版） | 1200 | 400 |
| 快速抓取（美化版/导出版） | 300 ~ 600 | 600 ~ 1000 |

> 💡 提示：使用桌面版网站（电脑 UA）效果更佳，批量抓取时建议保持页面在前台。
