# DeepSeek 对话全文抓取器

一个用于 DeepSeek 聊天页面的油猴脚本，自动滚动加载并保存完整对话为 TXT 文件。

## ✨ 功能

- 自动识别滚动容器，模拟触摸滑动触发懒加载
- 支持向上、向下、双向抓取
- 可调节滚动间隔和步长
- 实时显示抓取进度和字符数
- 停止后自动下载 TXT 文件
- 美观的毛玻璃 UI，可折叠、可拖动

## 📦 版本说明

| 文件 | 说明 |
|:---|:---|
| `deepseek-scraper.user.js` | 基础功能版，简洁稳定 |
| `deepseek-scraper-gui.user.js` | 美化折叠版，界面更精致 |

## 🚀 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 点击上方脚本文件，复制全部代码。
3. 打开 Tampermonkey 控制面板，点击“新建脚本”，粘贴并保存。
4. 访问 [DeepSeek 聊天页面](https://chat.deepseek.com/)，右侧会出现控制面板。

## 🎮 使用方法

1. 进入任意对话页面，控制面板会自动出现。
2. 根据需要点击“向上滚动抓取”、“向下滚动抓取”或“抓取全部”。
3. 可调整“间隔”和“步长”参数优化速度。
4. 抓取完成后自动下载 TXT 文件，每条消息以 `---` 分隔。

## ⚙️ 推荐参数

| 场景 | 间隔(ms) | 步长(px) |
|:---|:---|:---|
| 稳定抓取 | 1200 | 400 |
| 快速抓取 | 40 | 1000 |

> 💡 提示：使用桌面版网站（电脑UA）效果更佳。
